# ⚓ Морской бой на два телефона

Простая онлайн-игра «Морской бой» для двух игроков. Оба открывают сайт в браузере
телефона, один создаёт комнату и получает 4-значный код, второй вводит код — и они
играют в реальном времени. Ничего устанавливать не нужно.

## Как запустить

```bash
npm install      # один раз
npm start        # запустит сервер на http://localhost:3000
```

### Играть с двух телефонов в одной Wi-Fi

1. Запустите сервер на компьютере (`npm start`).
2. Узнайте IP компьютера в локальной сети:
   ```bash
   ipconfig getifaddr en0     # обычно Wi-Fi на Mac; если пусто — попробуйте en1
   ```
3. На **обоих** телефонах (в той же Wi-Fi) откройте в браузере `http://ВАШ_IP:3000`,
   например `http://192.168.1.42:3000`.
4. Один телефон — «Создать игру», второй — вводит код и «Войти».

> Компьютер с сервером должен быть включён и в той же сети всё время игры.

### Играть из любой точки (через интернет)

Нужно задеплоить сервер на бесплатный хостинг Node.js — тогда телефонам не нужна общая
Wi-Fi, только код комнаты. Проект готов к деплою как есть (слушает `process.env.PORT`).
Варианты: [Render](https://render.com), [Railway](https://railway.app),
[Fly.io](https://fly.io), [Glitch](https://glitch.com).

Пример для Render: создать Web Service из репозитория, Build Command `npm install`,
Start Command `npm start`. После деплоя открывать выданный URL на обоих телефонах.

## Как играть

1. **Расстановка.** Корабли ставятся от большого к малому. Нажимайте на поле, чтобы
   поставить очередной корабль. Тап по строке статуса переключает ориентацию
   (горизонтально/вертикально). Тап по уже поставленному кораблю — убрать его.
   Кнопка **🎲 Случайно** расставит весь флот автоматически. Когда флот готов —
   **Готов к бою**.
2. **Бой.** Ходите по очереди, стреляя по полю соперника. Попал — ходишь ещё раз,
   промахнулся — ход переходит. Потопили весь флот соперника — победа.

Флот (классический): один 4-палубный, два 3-палубных, три 2-палубных, четыре
1-палубных. Корабли не могут касаться друг друга даже углами.

## Как устроено

- **`server.js`** — Node.js + Express (раздаёт статику) + Socket.IO (связь в реальном
  времени). Сервер авторитетен: он хранит расстановку кораблей обоих игроков и сам
  считает попадания. Телефон соперника никогда не получает вашу карту — только
  результаты своих выстрелов. Комнаты хранятся в памяти (сбрасываются при перезапуске
  сервера).
- **`public/`** — фронтенд без сборки: `index.html`, `style.css`, `game.js`.

## Границы

- Без аккаунтов и базы данных — только игровая сессия.
- Если игрок выходит/теряет связь, комната закрывается, второму показывается сообщение.
